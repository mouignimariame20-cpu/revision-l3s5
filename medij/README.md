# MédiJ

Application de révision pour étudiants en médecine : chacun ajoute ses cours (PDF, PowerPoint, Word, photos) et MédiJ en fait des fiches, flashcards et QCM, avec la méthode des J (J1, J3, J7, J15, J30), la répétition espacée, la progression et le mode hors ligne.

Site statique publié par GitHub Pages.
